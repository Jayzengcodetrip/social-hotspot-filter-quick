# 热点新闻（快速版）

让你的 AI Agent 完整读取九个固定来源，找出多个平台共同关注的中文热点，并保留各平台的原始标题和链接。

**把这个仓库链接发给支持 Skills 的 Agent，让它安装后运行即可。** Agent 需要具备交互式浏览器控制、本地文件读写和脚本执行能力；只有网页搜索功能的聊天工具无法完成这套流程。

## 复制这段话给你的 Agent

```text
请从这个 GitHub 仓库安装 social-hotspot-filter-quick：
https://github.com/Jayzengcodetrip/social-hotspot-filter-quick

先阅读 README.md 和 SKILL.md，确认当前环境支持的 Skill 安装方式。
安装完整仓库，保留 SKILL.md、agents/、references/ 和 scripts/ 的相对结构，
不要只下载 SKILL.md；如果已有同名 Skill，先检查并保留本地修改。

安装后检查浏览器控制、Python 3 和 Node.js 是否可用。
按 Skill 要求优先检查能否连接我的现有 Chrome 会话；需要连接或登录时告诉我。
准备就绪后，使用这个 Skill 给我生成最新的跨来源共同热点 Top 10（快速版）。
如果当前环境不支持安装或缺少必要能力，请明确说明具体缺项，不要声称安装或运行成功。
```

安装完成后，日常只需说：

```text
使用 social-hotspot-filter-quick，给我最新热点快速版。
```

也可以指定数量：

```text
使用 social-hotspot-filter-quick，给我最新的跨来源共同热点 Top 5（快速版）。
```

需要配置定时执行时，再单独让 Agent 使用所在平台的定时任务功能。本仓库本身不包含调度服务。

## 它会做什么

按固定顺序，直接读取以下九个来源的当前内容：

| 来源 | 采集范围 |
| --- | --- |
| 微博 | 热搜榜 50 个位置 |
| 知乎 | 热榜 30 个位置 |
| B站 | 热搜榜 30 个编号位置 |
| 百度 | 热搜榜 50 个位置 |
| 抖音 | 公开热榜 50 个位置及页面更新时间 |
| 界面新闻 | 当前首页全部范围内新闻卡片 |
| 新京报 | 当前首页全部范围内新闻卡片 |
| 财新 | 当前首页全部范围内新闻卡片 |
| 人民日报 | 当日电子报全部版面的标题 |

Agent 将描述同一事件的条目归为一个话题，再按统一规则排名：

1. **至少出现在两个不同核心域名上**，才能进入榜单。
2. 先按**平台覆盖数**从多到少排序。
3. 覆盖数相同时，再按**话题命中数**从多到少排序。
4. 两项都相同则并列排名；默认最多输出 10 个话题，不足时按实际数量输出。

同一平台的多个不同条目可以增加话题命中数，但这个平台只贡献一次覆盖数。娱乐、体育、科技、民生等话题适用相同规则。

报告包含采集时间、浏览方式、九源完整性结果、排名总表，以及每个入选话题在各平台的原始标题和链接。B站、抖音在没有可用条目链接时可以只保留原始标题。

## “快速版”的含义

快速版省去逐话题的额外补充检索和事件概述，仍然要求完整采集九个来源、审阅聚类、补齐规定的入选链接并通过报告校验。

它不进行额外的独立事实核查。**多个平台同时出现某个说法，不代表这个说法已经得到证实。** 涉及传言、辟谣或争议时，应保留原始来源的归属和不确定性。

“快速”是相对于含补充研究的流程而言，不承诺固定耗时。实际用时取决于页面加载、登录状态、Agent 能力、重试及当次内容量。

## 运行条件与兼容性

这是按 [Agent Skills 目录约定](https://agentskills.io/specification)组织的指令和辅助脚本包。能识别目录格式，不等于已具备执行本 Skill 的全部能力。

- **Agent：**能够安装或加载本地 Skill，读写文件并运行命令；安装路径以该 Agent 当前文档为准。
- **浏览器：**能够实际打开原网站、读取当前页面标题与链接、滚动和观察加载状态。优先检查现有 Chrome 会话；其他浏览方式按 `SKILL.md` 的条件使用。
- **数据保存：**能够通过浏览器或宿主正式支持的方式，把当次观察到的完整标题、链接和采集证据保存为本地文件。某些 Codex 环境可使用当前任务日志传输，其他环境不需要也不应寻找 Codex 私有目录。
- **Python 3：**辅助脚本使用标准库，无需安装第三方 Python 依赖。
- **Node.js：**用于重放和检查采集完整性记录。若 `node` 不在命令路径中，可用 `SHF_NODE` 指定可执行文件。
- **网站访问：**九个固定原始来源均须可访问。若页面要求登录或验证码，由用户自行完成；仓库不提供登录凭据。

首发包本地脚本测试环境：Python 3.9.6、Node.js 26.2.0、macOS。尚未逐一验证所有 Agent 产品、操作系统和浏览器组合。其他环境应先执行下方自检，再检查实际浏览器能力。

任何一个核心来源无法完整读取，都应按 Skill 的重试、等待用户处理或终止规则执行，不能用其他来源、搜索摘要或已有榜单替代。页面真实改版导致固定榜单数量变化时，也应先停止并确认。

## 手动安装

1. 下载或克隆整个仓库。
2. 按你的 Agent 当前官方文档，将完整目录放到它支持的 Skill 位置，目录名保持为 `social-hotspot-filter-quick`。
3. 确认该目录下直接存在 `SKILL.md`，且能找到同层的 `references/`、`scripts/` 和 `agents/`。
4. 按 Agent 的要求刷新或重新加载 Skills，检查是否能识别该 Skill，然后执行一次自然语言调用。

不要把 `references/` 和 `scripts/` 拆到其他位置，也不需要安装完整版 Skill。详细操作约束以 [SKILL.md](SKILL.md) 为准。

## 文件结构

```text
social-hotspot-filter-quick/
├── SKILL.md                 # Agent 执行规则
├── README.md                # 项目介绍与安装使用方法
├── LICENSE                  # MIT 许可证
├── agents/openai.yaml       # 支持该元数据的客户端可使用的显示信息
├── references/              # 采集记录、链接约定及运行说明
└── scripts/                 # 辅助脚本、报告生成器、校验器及测试
```

实际运行产生的原始采集、证据、聚类、计时和报告应保存在安装目录之外。本仓库不随附用户的采集记录、浏览器会话或历史报告。

## 本地自检与开发

在仓库根目录运行：

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
node --test scripts/test_browser_collection.mjs
```

这些测试使用合成样例检查脚本和规则，不访问九个新闻来源，也不等于一次真实热点采集成功。

准备真实运行时，Agent 应先阅读 [采集运行说明](references/collection-runtime.md)，完成浏览器采集、证据记录和聚类审阅，再调用统一报告入口：

```text
python3 <skill-dir>/scripts/finalize_report.py --run-dir <run-dir> --limit 10
```

该命令校验已有采集结果并生成报告；浏览器采集和事件聚类由 Agent 按 Skill 完成。校验结果能检查记录完整性、计数、排序和报告结构，不能证明网页内容真实或模型聚类判断正确。

遇到问题可提交 Issue，附上 Agent 名称、系统、Python/Node.js 版本及去除私人信息后的具体错误。修改后请运行测试，确保完整采集、原始标题保留、两域名入选门槛和统一排名规则保持一致。
